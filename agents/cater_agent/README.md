# 🥪 Catering Agent (`cater_agent`)

The Catering Agent provides curated 4-course catering menu suggestions to serve at team lunch meetings, proposing 3 distinct menus composed of dishes from the company's in-house catering service.

## Menus Offered
1. **Option 1 (Buffalo Chicken Wrap Combo)**: `buffalo chicken wrap`, `mixed greens salad`, `chocolate cookie`, `assorted sodas`
2. **Option 2 (Veggie Tacos Combo)**: `veggie tacos`, `snow pea salad`, `apple tartlets`, `tea service`
3. **Option 3 (Lamb Vindaloo Combo)**: `lamb vindaloo`, `spiced cauliflower`, `naan`, `orange-mint spa water`

## Endpoints
- Port: `8083`
- A2A Agent Card: `http://localhost:8083/a2a/app/.well-known/agent-card.json`
- RPC Endpoint: `http://localhost:8083/a2a/app/`
