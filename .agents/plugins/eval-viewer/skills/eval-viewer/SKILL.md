# ADK Evaluation Report Viewer Skill

This skill manages the local Node.js Express sidecar server for browsing, inspecting, and serving interactive evaluation results generated by `agents-cli eval grade`.

## Quick Operations

### 1. Launch the Eval Sidecar Server
To start the sidecar server in the background:

```bash
node .agents/plugins/eval-viewer/sidecar/server.js &
```

The dashboard will be available at: **http://localhost:8088**

### 2. Query Available Evaluation Reports
Query the sidecar's REST API for a JSON summary of all evaluated agents and test runs:

```bash
curl -s http://localhost:8088/api/reports
```

### 3. Key Endpoints

| Endpoint | Description |
|---|---|
| `http://localhost:8088/` | Main Interactive Dashboard |
| `http://localhost:8088/view/:agent/latest` | Opens the latest report for that agent in the interactive viewer |
| `http://localhost:8088/reports/:agent/:filename` | Raw standalone HTML grade results report |
| `http://localhost:8088/json/:agent/:filename` | Raw JSON grade metrics & case traces |
| `http://localhost:8088/api/reports` | REST API listing all historical evaluation runs |
